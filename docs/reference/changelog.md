# Changelog

Laravel OpConsole follows [Semantic Versioning](https://semver.org/). The authoritative, continuously updated changelog lives in the repository at [`CHANGELOG.md`](https://github.com/ashraftalha/laravel-opconsole/blob/main/CHANGELOG.md) — this page is not a copy that can drift out of sync with it.

For version-specific migration steps (config keys to merge, assets to republish, behavior changes to review), see the [Upgrade Guide](/reference/upgrade).

## Latest release

**v1.11.0** — Laravel Octane and Swoole support (health checks, System information card, Reload Octane workers operation, and a guard that refuses timed actions inside Swoole workers), a Failed jobs tab with per-job retry, and expanded System information (Performance, PHP extensions, Database groups).
